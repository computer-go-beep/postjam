# Postjam agent skill

Lets Claude Code, Codex, Cursor and other agents post reels and slideshows to TikTok, Instagram, YouTube, Facebook and Threads through [Postjam](https://postjam.app), once or on a schedule.

```bash
npx skills add computer-go-beep/postjam -g
```

The skill connects the agent to Postjam's MCP server at `https://mcp.postjam.app`. You sign in through the browser the first time it is used.
